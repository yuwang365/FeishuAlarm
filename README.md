# 飞书牛马助手 (FeishuAlarm)

一个用于自动提醒并辅助飞书（Lark）打卡的 Android 应用。

## 主要功能

*   **定时监控**：支持设置多个监控时间点，自动在后台运行。
*   **位置判定**：到达预设的打卡地点范围内（使用系统原生定位，不依赖 GMS）才触发打卡。
*   **智能唤起**：
    *   如果手机已解锁，直接打开飞书。
    *   如果手机处于锁屏状态，发送高优先级通知并在解锁后自动跳转。
*   **排除周末**：默认只在工作日运行。
*   **前台服务**：使用前台服务（Foreground Service）确保进程在后台不被系统轻易杀掉。

## 所需权限

*   **精确位置权限** (`ACCESS_FINE_LOCATION`)：用于判定是否到达打卡点。
*   **后台定位权限** (`ACCESS_BACKGROUND_LOCATION`)：确保锁屏或应用在后台时仍能获取位置。
*   **悬浮窗权限** (`SYSTEM_ALERT_WINDOW`)：用于在某些系统上辅助唤起应用。
*   **通知权限**：发送打卡提醒。
*   **闹钟权限**：设置精确的触发时间。
*   重要说明！！！：需手动添加保活，允许自启动，允许后台定位，一键清除锁定，避免手动或者系统误杀app。

## 技术栈

*   **语言**：Kotlin
*   **UI 框架**：Jetpack Compose (Material 3)
*   **组件**：
    *   `AlarmManager` & `BroadcastReceiver` (定时任务)
    *   `LocationManager` (原生定位)
    *   `Foreground Service` (后台保活)

## 开发说明

该项目已针对 Android 14+ (API 34/35) 进行了适配，使用了 `specialUse` 类型的前台服务。由于移除了 Google Play 服务依赖，该应用可在没有 GMS 的国产手机上正常运行。
